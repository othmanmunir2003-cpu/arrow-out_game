## 🌟 نبذة عن اللعبة
**Arrow Out** هي لعبة ألغاز وتفكير ذكية وممتعة تعتمد على توجيه وإخراج الأسهم المتشابكة من اللوحة دون حدوث أي اصطدام. تتميز بتصميم أنيق ومستوحى من لوحات الإرشاد المرورية مع دعم كامل للثيمات المتعددة، المؤثرات الصوتية الحية، والتحديات المتصاعدة.

### ✨ المميزات الرئيسية
* **تصميم فريد:** مستوحى من لوحات إرشادية أنيقة مع دعم الوضعين الفاتح والداكن (Light/Dark Mode).
* **مستويات متدرجة الصعوبة:** تتسع اللوحة وتزداد التعقيدات مع تقدمك في المراحل لتختبر ذكاءك وتركيزك.
* **ثيمات ومظاهر متعددة:** أشكال لوحات متنوعة (الورق، نيون سايبر، الغابة، المحيط، الذهب الملكي) يمكنك فتحها بالعملات المكتسبة.
* **مؤثرات بصرية وصوتية غنية:** اهتزازات تفاعلية (Haptic feedback) وأصوات موسيقية متناسقة عند الإنجاز والحل.
* **إمكانية التحويل لتطبيق موبايل (APK):** مهيأة بالكامل للعمل ك تطبيق هاتف عبر Capacitor و GitHub Actions.

## 🌟 About The Game
**Arrow Out** is an engaging and strategic puzzle game where you untangle and guide intertwined arrows out of the board without collisions. Featuring a sleek signboard aesthetic, multiple themes, rich audio feedback, and progressive challenges.

### ✨ Key Features
* **Sleek Aesthetic:** Clean signboard design with light and dark mode support.
* **Progressive Levels:** Grid sizes expand and complexity increases as you advance through the worlds.
* **Custom Themes:** Unlockable board styles (Classic Paper, Cyber Neon, Forest, Ocean, Royal Gold).
* **Rich Audio & Haptic Feedback:** Immersive sound effects and subtle vibrations for every successful move.
* **Mobile Ready:** Easily build into an Android APK using GitHub Actions and Capacitor.

---

## 🚀 How to Build APK via GitHub Actions
1. Upload this repository to GitHub.
2. Ensure the workflow file `.github/workflows/android.yml` is present.
3. GitHub Actions will automatically compile the project using Node.js and Gradle.
4. Download your generated `app-debug.apk` from the **Actions -> Artifacts** section.
